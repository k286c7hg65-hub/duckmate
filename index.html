◆ 为什么做 DuckMate

第一性拆解：桌面机器人是「玩具」，不是「AI 原生设备」。消费级双足机器人在中国是空白。

PROBLEM 01

市场已验证，但没人做中国版

海外 MicroDuck（25cm 开源鸭）$499 预售爆单，Q4 出货。但 25cm 方案进口舵机 15 只 ¥4,500+，做不了中国 C 端（¥1,999-2,599 定价结构性亏损）。

SOLUTION 02

大鸭路线：更大身体 + 国产化

Open Duck Mini v2（42cm，同工程师同源）→ 14 只飞特 STS3215（¥60-70/只）国产化，量产整机 ¥1,500-1,800 目标。尺寸升级 = 扭矩 3 倍 = 能踢球。

EDGE 03

差异化：踢球 + AI 素养 + 开源生态

RL 训练踢球技能（拳头差异化）、中文 AI 素养教育内容、Apache-2.0 全开源 + 同济教程生态，打样成本趋零，组装路线验证过。

◆ 市场分析

消费机器人的胜利公式 = 平价硬件 × 开源生态 × 社区内容。MicroDuck 已验证，Anki 已证伪（闭源单打，公开报道累计融资超 $2 亿后倒闭）。DuckMate 完全沿胜利公式设计。

GLOBAL 01

全球：开源时刻已到

MicroDuck $399 预售 2026-08-27 开，爆单至 Shopify UI 限额（官方博客原话，含 HF 联创 Thomas Wolf）。同门 Reachy Mini 已售 10,000+ 台。发布 4 天社区训出翻筋斗/霹雳舞/激光追踪（社区实测）。

CHINA 02

中国：供给真空

MicroDuck 首发仅北美/欧洲/英国，圣诞前发货。中国用户需 ¥3,500+ 税运且 2027 年才到手（官网 FAQ 核验）。42cm 大鸭 = 无官方对手、无复刻量产、中文内容生态刚起步的空白位。

PLAY 03

我们站的位置

把「社群能自装的套件」升级为「开箱即用的品牌整机 + 内容体系」，正是 MicroDuck 在欧美所做的事的 中国 + 大尺寸版。需求真实且冲动，不凭空造需求。

WHY L1 FIRST

为什么极客是第一战场

MicroDuck 8/27 爆单人群就是极客（官方博客一手）。决策快、毛利高、品牌放大器（发烧友 → KOL → 大众）。唯一有现成证据的入口。

WHY L2 MAIN

为什么 C 端是主战场

中国家庭付费意愿未验证（M1 必测），需内容体系 + 品牌信任长线投入。C 端品牌从极客口碑长出来，比广告便宜。

DEMAND 03

需求不是「会动的 iPad」

内容金字塔只承载屏幕给不了的三种具身独有：物理因果、真实责任、身体性惊喜。能上屏幕的内容不上机器人（内容方法论 4 轮审计验证）。

◆ 竞品分析：不撞 MicroDuck，做尺寸升级互补品

克隆同尺寸 = 正面撞车必输（$399 官方 + 复刻党规模化成本更低）。42cm ODM 与 MicroDuck 是同一位工程师 Antoine Pirrone（Pollen R&D）的作品，站在同源开源上做更大版本，训练方法论一脉相承。

◆ FAQ

为什么 42cm「大鸭」而不是 25cm MicroDuck？
25cm 方案 15 只进口舵机要 ¥4,500+，C 端定价 ¥1,999-2,599 结构性亏损。42cm ODM 同工程师同源，14 只国产 STS3215 只要 ¥840-980，扭矩还大 3 倍，能踢球。成本结构和能力都赢。
开源协议怎么算？能用它做产品卖钱吗？
Apache-2.0：全部图纸/BOM/训练栈公开，商用合规，可闭源衍生。开源生态 = 打样成本趋零 + 组装路线验证过（同济教程实测 ¥3,000 整机）。
「RL 踢球」是真的自己学会的吗？
是。MuJoCo 仿真 + 强化学习训练策略 → 导出 ONNX → 部署真机。训练轨已跑通第一个 gate（standing 150M，AutoDL 4090，成本 <¥10 预算口径）——验收发现学到的是站住而非行走：站姿 imitation 正奖励 + 跌倒惩罚缺失，站住成为奖励结构下的局部最优。未签收，修复重训中（独立 Codex 审计 + trace 逐步证据闭环）。质量闸门实证：学到站住不算完成。踢球策略 2027-01 M2 交付。
跟普通 AI 玩具/机器人课有什么区别？
孩子要的不是内容，是活的回应。DuckMate 只承载屏幕给不了的三种「具身独有」：物理因果（说踢球它就踢飞）、真实责任（会摔倒要充电会记住你）、身体性惊喜（亲眼看到它长大）。
现在能做什么？怎么参与？
M0 共创会准备中（三张报价单已就绪，日期待 Sky 定）。极客可登记预售意向（¥500 可退），早鸟 ¥3,999 锁定 + 编号铭牌 + 共创社群。进度实时更新在 Robot 研究群。
最大的风险是什么？
预售不及 N=200（M1 gate 不通过则止步）。缓解：极客社区预热 + 早鸟价 + 共创社群锁意向；真机舵机损坏风险靠「虚拟训练成熟再上真机」规避。完整风险清单见项目管理文档。
