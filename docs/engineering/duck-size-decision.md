# 大鸭 vs 小鸭：第一性原理分析（2026-09-03）

> Sky 提问「我们做大鸭还是小鸭？」——DuckMate 硬件路线最终决策

## 一、问题拆到公理

DuckMate 的本质：卖「会走、会互动、承载 AI 素养内容的家庭机器人鸭子」。硬件是载体，不是产品本身。

**公理（不可再拆）：**
1. **供应链**：三人团队（Sky + 友A PCB + 友B 模具），无自建硬件研发 → 硬件必须开源可用或现成可采
2. **成本**：C 端目标价 ¥1999-2599，毛利必须为正 → 硬件成本需显著低于售价
3. **时间**：MicroDuck Q4 出货（12 月速度线），共创会 M0 下周 → 工程周期决定窗口
4. **软件资产**：已有 9 ONNX 策略 + orchestrator 行为层 + 踢球训练（MicroDuck 规格 25cm/15×XL330/737g）
5. **差异化**：MicroDuck 官方就是 25cm $399 → 克隆同尺寸 = 正面撞车必输
6. **工厂协同**：友A/B 能力（PCB/精密模具）应对硬件路线直接可用

## 二、两方案对照（全部一手数据）

| 维度 | 小鸭（25cm MicroDuck 克隆） | 大鸭（42cm Open Duck Mini v2） |
|---|---|---|
| **舵机** | XL330×15 ≈ **¥4500+**（¥299/个，fanhao375）| STS3215×14 ≈ **¥840-980**（¥60-70/个，fanhao375 一手）|
| **整机成本** | ¥5500-6000（舵机占 80%）| **¥2500-3000**（同济子豪兄实测「3000 元左右」）|
| **C 端 ¥1999-2599** | ❌ 卖一台亏一台 | ✅ 有毛利，量产可再降 |
| **硬件可得性** | ❌ 闭源逆向（fanhao375：「自己造比买贵」）| ✅ 全开源 CAD/STL/BOM + 143 STL + 中文教程 |
| **工程周期** | 6-12 个月（PCB 墙+结构逆向）| **几周-2 月**（套件+组装指南现成）|
| **软件资产** | ✅ 9 ONNX 直接跑 | ⚠️ 官方策略作废，但 ODM 自有 Playground 训练栈 + 走路策略现成 |
| **差异化** | ❌ 撞 MicroDuck 官方 + 复刻党 | ✅ 无官方对手（MicroDuck 是 25cm）|
| **供应链** | ❌ XL330 进口无国产平替（S288 力矩 62%/12.6V/协议不兼容）| ✅ 深圳飞特国产直采 |
| **工厂协同** | 友A/B 帮不上核心（舵机是进口成品）| ✅ PCB 友A + 结构模具友B 直接可用 |
| **安全** | 737g 桌面，风险低 | 2.1kg 需设计缓解（软壳/限速/防倾倒），目标 8+ |

## 三、推导

1. **成本墙**：小鸭 ¥5500+ 硬成本 vs C 端 ¥1999-2599 → 结构性亏损。大鸭 ¥2500-3000 可盈利。→ 大鸭
2. **供应链墙**：XL330 = 进口 + 贵 + 无平替（唯一物理硬约束）；STS3215 = 国产可直采。→ 大鸭
3. **差异化**：小鸭克隆 = 撞 $399 官方 + fanhao375 复刻党（他们规模化成本更低）；大鸭 = MicroDuck 生态的「尺寸升级互补品」。→ 大鸭
4. **工程周期**：闭源逆向 6-12 月 vs 开源套件几周。窗口（Q4）只允许大鸭。→ 大鸭
5. **同源性**：ODM 和 MicroDuck 是**同一位工程师**（Antoine Pirrone，Pollen R&D）的作品——大鸭 = 站在同源开源上做「更大版本」，不是异类
6. **软件迁移成本可控**：orchestrator 行为层（7 原子/4 组合）硬件无关可迁移；行走策略 ODM 现成；踢球等重训走 ODM Playground（训练方法论/工具链全保留）

## 四、反方自检（找天敌）

**最致命反方：「MicroDuck 成功已证明 25cm 是正确尺寸，42cm 大鸭没有市场需求验证」**
→ 回应：MicroDuck $399 卖爆是**规模化成本下的产物**，不是尺寸验证。中国极客买它 = 没有替代品 + 官方生态。大鸭满足「更大存在感/可抱/地面行走」——同济子豪兄社群已有人做出实机在走、在晒视频（需求真实存在）。最终验证不靠拍脑袋，靠 M1 极客预售 N=200 gate。

**次致命反方：「2.1kg 对孩子有倾倒/砸伤风险」**
→ 真实风险，承认。缓解 = 软壳 + 限速 + 防倾倒检测 + 目标 8+ 监护人陪伴。这是产品设计要求，不是路线否决项。小鸭 737g 虽安全但 25cm 桌面玩具缺「宠物感」——DuckMate 卖的就是陪伴感。

**第三反方：「虚拟鸭资产（microduck-rl-fork 踢球训练）白投了」**
→ 部分物理策略需重训，但：行为编排思想/内容金字塔/训练方法论/工具链全保留；microduck-rl-fork 是训练**行为窗口验证**（verify_kick_window）——方法论直接迁移到 ODM Playground。轨 A 冻结纪律不变：虚拟鸭继续作内容孵化器。

## 五、结论

**大鸭（ODM 42cm 路线）。** 六条公理全指向大鸭，小鸭仅「官方策略直接复用」一条胜（且被行为层可迁移削弱）。

**认的代价**：25cm 官方策略不能直接用，部分技能需在 ODM 上重训（有现成路径）。

**决策后动作**：
1. BP v2.3：产品规格改 42cm/成本 ¥2500-3000/毛利场景重算/对比表 MicroDuck 行改「互补非竞争」
2. 共创会备料升级：ODM BOM/CAD/STL 底稿 + 同济子豪兄知识库（BOM 表/套件渠道）+ 问友B「ODM 结构件注塑模具报价」
3. fanhao375 仓 + ODM Playground 加入技术栈研究
4. M1 极客预售验证「42cm 大鸭」需求（N=200 gate）
