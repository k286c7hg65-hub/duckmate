## 一、核心结论（先看这个）

1. **舵机硬约束结论被改写**：Open Duck Mini 用 **Feetech STS3215（深圳飞特，国产）** 14 个 = €196（≈¥1530），不是 MicroDuck 的 XL330（15×€45.76 ≈ ¥5350）——**国产方案省 ¥3800+，之前「舵机依赖进口」的物理硬约束不成立**（至少在「开源双足」层级）
2. **整机 BOM 官方合计 ≈ €390（≈¥3000）**，最低价 ≈ €330（≈¥2580）；国内组装估 ¥2800-3500（含运费损耗）
3. 结构件成本 ≈ 0（3D 打印 500g PLA ≈ ¥150，友B 若开模另算）——之前 BP「舵机占 BOM 65-80%」在 STS3215 方案下降为 ~50%

## 四、对 BP 的影响（需同步）

1. **§4.3 生死变量改写**：舵机从「XL330 批量议价 + 国产替代评估」→「**STS3215 国产直采为主方案**」；XL330 仅在需要更高扭矩/精度时备选
2. **成本三场景重估**：原 B/C 保守场景（舵机批量 $130-180）过时——若国产舵机方案成立，C 端整机 ¥1999-2599 的毛利空间显著扩大
3. **对比 MicroDuck $399**：MicroDuck 用 XL330（贵 3 倍舵机）+ 欧洲供应链；我们国产化后成本优势从 -30-50% 扩大到可能 -40-60%
4. ⚠️ 验证项：STS3215 扭矩/精度是否够 MicroDuck 级动作（踢球/快速走）——Open Duck Mini 已用同款走路（sim2real 视频实证），但踢球/抗冲击需实测
