## 1. 执行摘要

**我们做什么**：面向中国家庭与教育场景的双足 AI 教育机器人。基于已验证的开源具身智能软件栈（Apache-2.0），用国产供应链把欧美 $399 级产品的完整体验，以 ¥1999-2599 带给中国用户，差异化定位在 **AI 素养教育**（非编程红海）。

**为什么是现在（三窗交汇）**：
1. **需求验证窗**：MicroDuck（Pollen Robotics）2026-08-27 预售爆单——官方原话 "reached the Shopify UI limit"；同门 Reachy Mini 已售 10,000+ 台
2. **中国真空窗**：MicroDuck 首发仅北美/欧洲/英国；中国用户需 ¥3500+ 税运且 2027 年才到手
3. **供应链红利窗**：创始团队含 PCB 量产厂 + 精密模具厂实控人，BOM 成本可较欧美压低 30-50%

**第一战场（v2.1 收敛）**：**极客/创客预售**——MicroDuck 爆单人群中国真空（唯一有现成证据的入口），验证产品 + 拿现金 + 攒口碑；C 端家庭为**主战场**（内容金字塔先行：人格/互动/学习/创造四层）；教培机构为**试探**（3 家免费试用，验证不过就砍）。学校/特教**明确不做**（结构性不可进入）。

**团队**：3 位创始人覆盖硬件量产（PCB 代工厂主）、精密结构/模具（黄金首饰模具厂主）、产品/商业/合规/出海（16 年金融科技与电商支付，前蚂蚁/字节/华为）。

**融资需求**：天使轮 ¥300-500 万，出让 10-15%（框架，待定），12 个月至首批 500 台交付。

**核心风险与对策**：舵机成本（生死项，共创首日实测，三路对策）；MicroDuck Q4 出货（外部观测 gate，非依赖项）。

**结构性结论**：消费机器人的胜利公式 = 平价硬件 × 开源生态 × 社区内容。闭源单打（Anki）已证伪，开源众包（MicroDuck）已验证。本项目的商业模式完全沿胜利公式设计。

### 2.2 中国：需求真空 + 客户路径（v2.1 收敛）

**客户第一性重问：谁最愿意为「会走路的 AI」付钱？**
不是「焦虑的家长」（决策慢、红海、品牌冷启动难），而是**「冲动买」的极客 + 机构（教具需求）**。但「有需求」≠「我们能进入」——学校/特教虽有需求，**结构性不可进入**（资质/渠道/准入是上市公司级投入），不占版面。

**可进入的客户路径（只保留有证据或可验证的）**：

| 路径 | 客户 | 证据 | 角色 |
|---|---|---|---|
| L1 极客/创客 | 开发者 | ✅✅ MicroDuck 爆单=这群人；中国真空（税运 ¥3500+/2027 到手）| **第一战场**：验证+现金+口碑 |
| L2 C 端家庭 | 家长(6-14) | 🟡 AI 素养是趋势，付费意愿 M1 访谈验证 | **主战场**：品牌+订阅（内容先行）|

| ~~学校 K12~~ | | ❌ 招投标资质/渠道体系/回款 = 上市公司级 | 不做 |
| ~~特教/自闭症~~ | | ❌ 医疗专业准入/循证/合规 = 无路径 | 不做 |

**为什么极客是第一战场**：MicroDuck 8/27 爆单人群就是极客（官方博客一手）；中国真空明确（官网 FAQ）；决策快、毛利高、品牌放大器（发烧友→KOL→大众）。**唯一有现成证据的入口。**

**为什么 C 端是主战场不是第一**：中国家庭付费意愿**未验证**（M1 必测），需内容体系+品牌信任长线投入；C 端品牌从极客口碑长出来比广告便宜。

### 2.3 市场规模推算（自下而上，方法披露）

**推算方法（非第三方报告，均为可复核逻辑）**：
- 锚点 A：MicroDuck 首周预售爆单 → 保守估计首年全球出货 5,000-20,000 台（$399 单价 → $2-8M 营收量级，与其 Shopify 爆单现象一致）
- 锚点 B：Reachy Mini 累计 10,000+ 台（$1,000+ 单价，教育/研究渠道）
- 锚点 C：中国 K12 学生约 1.5 亿人（教育部公开统计常识），机器人/编程教育渗透率极低

**TAM（3 年视角）**：中国教育陪伴机器人可寻址市场 ≈ 愿意为儿童 AI 硬件支付 ¥1500-3000 的城市家庭。假设目标城市中产家庭 3,000 万户、3 年渗透 0.1% → **约 3 万台/年 ≈ ¥6-9 亿**（推算，非第三方数据）

**SAM（本项目 3 年）**：极客 + 线上直营 + 机构试探可触达 ≈ 5,000-15,000 台/年（¥1-3.5 亿）

**SOM（本项目 3 年保守目标）**：3,000-5,000 台/年（¥700-1300 万）——**验证性规模，不为份额叙事融资**

> ⚠️ 以上为推算框架，真实市场规模以共创后渠道访谈 + 预售数据校准（见 11. 里程碑 M1）。

## 3. 产品与技术

### 3.1 产品定义（v2.0：五层模型升级）

| 维度 | 规格 |
|---|---|
| 形态 | 双足小型机器人（14 自由度级），IP 化外观（鸭/恐龙/宠物三选一）|
| 价位 | ¥1999-2599（旗舰）/ ¥1299（8-10 舵机入门款/极客开发版）|
| 目标用户 | 极客/创客（L1 第一战场）→ 6-14 岁儿童+家长（L2 主战场）|
| 核心场景 | 自训技能与二次开发（L1 极客）、AI 素养教育 + 陪伴（L2 C 端）|

**产品五层模型（v2.0 新增）**——价值在灵魂，成本在身体：

```
① IP 人格层：外观/性格/名字，可换 IP 壳（一台身体多张脸）→ 复购引擎（友B 模具）
② 交互层：中文语音/触摸/App → MicroDuck 无中文，我们补（自研）
③ 行为层：开源 9 策略 + 自训技能包 → Apache-2.0 合法复用
④ 学习层：AI 素养内容四层金字塔（见下）→ 订阅引擎
⑤ 身体层：14 自由度 + 传感器 + 主板（友A）+ 结构（友B）→ 成本底座
```

**关键判断**：①②③④全是软件/内容/IP（只有⑤是硬件）——产品的大部分价值不在身体而在灵魂。MicroDuck 只做了③+⑤；我们用①人格 + ②中文交互 + ④内容 = 把「创客玩具」升级成「家庭 AI 伙伴」。

### 3.1b 内容金字塔（v2.2 新增——Sky 已拍板）

**一句话定义**：DuckMate 内容 = 让孩子亲眼看见 AI 从想法变成动作。能上屏幕的内容不上机器人（否则 = 会动的 iPad）。

```
④ 创造层「我教它」← 最高留存：孩子训练它新技能（自训工具链）
③ 学习层「它教我」← 具身 AI 素养：课程发生在看它做/让它做/教它做，非屏幕播放
② 互动层「我和它玩」← 活物感基底：指挥家/追球/情绪剧场
① 人格层「它是谁」← 情感入口：名字/性格/成长打卡
```

- V1 最小集（Sky 拍板）：3 性格包 + 3 具身游戏 + 3 课程点（平衡 6-8/看 RL 9-11/行为编排 12-14）+ 编排 MVP
- 扩展性已设计：内容包 = 策略(ONNX) + DSL 行为脚本 + 场景资产，热加载，新内容零固件改动；分龄钩子 = 内容包年龄标签非三套产品
- 12 课（ai-course-summer）不是现成体系是**素材库与判断力资产**：内容方法论已验证（4 轮审计事实级严谨），体系化扩建是 M1-M3 任务
- 反方已过：内容成本是隐性第一风险 → 分层交付 + 开源杠杆 + 12 个月速度线

## 4. 商业模式

### 4.1 收入引擎（v2.0：三层递进）

```
L1 硬件（一次性，保本微利）→ 获客入口
    ├ 整机 ¥1299-2599（毛利 30-45%）
    └ 机构套装 ¥1-3 万/套（试探性，试点过了才放量）
L2 经常性（核心利润，毛利 50-80%）← 复购引擎
    ├ 教育订阅 ¥299/年：内容包季更（人格扩展/新游戏/新课程点），三段年龄标签适配（内容复利）
    ├ IP 配件 ¥99-399：换壳/服饰/球场（友B 模具复用）
    └ 技能包 ¥29-99：单行为下载（官方 + 社区）
L3 平台（远期，抽成 10-20%）
    └ 技能市场：社区上传技能，平台抽成（网络效应）
```

**递进逻辑**：L1 圈人 → L2 赚钱（复购引擎）→ L3 放大（社区自增长）
