## 1. 决策记录：为什么是大鸭（简短版）

### 1.1 问题拆到公理

DuckMate 的本质是卖「会走、会互动、承载 AI 素养内容的家庭伙伴」。硬件是载体，不是产品本身。六条公理：

1. **供应链**：三人团队（Sky + 友A PCB + 友B 模具）无自建硬件研发 → 硬件必须开源可用或现成可采
2. **成本**：C 端目标价 ¥1999-2599，毛利必须为正 → 硬件成本需显著低于售价
3. **时间**：MicroDuck Q4 出货（12 月速度线），共创会 M0 就在下周 → 工程周期决定窗口
4. **软件资产**：已有 9 ONNX 策略 + orchestrator 行为层（7 原子/4 组合）+ 训练方法论（MicroDuck 规格 25cm/15×XL330/737g）
5. **差异化**：MicroDuck 官方就是 25cm $399 → 克隆同尺寸 = 正面撞车必输
6. **工厂协同**：友A/B 能力（PCB/精密模具）必须对硬件路线直接可用

### 1.2 两案对照（全部一手数据，来源：duck-size-decision.md）

| 维度 | 小鸭（25cm MicroDuck 克隆） | **大鸭（42cm Open Duck Mini v2）** |
|---|---|---|
| 舵机 | XL330×15 ≈ **¥4500+**（¥299/个，fanhao375 ✅） | **STS3215×14 ≈ ¥840-980**（¥60-70/个，fanhao375 ✅） |
| 整机成本 | ¥5500-6000（舵机占 80%） | **¥2500-3000**（同济子豪兄实测「3000 元左右」✅✅） |
| C 端 ¥1999-2599 | ❌ 卖一台亏一台 | ✅ 量产可达正毛利（见 §5.2） |
| 硬件可得性 | ❌ 闭源逆向（fanhao375：「自己造比买贵」✅） | ✅ 全开源 CAD/STL/BOM + 143 STL + 中文教程 ✅ |
| 工程周期 | 6-12 个月（PCB 墙 + 结构逆向） | **几周-2 月**（套件 + 组装指南现成 ✅） |
| 软件资产 | ✅ 9 ONNX 直接跑 | ⚠️ 官方策略作废，但 ODM Playground 训练栈 + 走路策略现成 ✅ |
| 差异化 | ❌ 撞 MicroDuck 官方 + 复刻党 | ✅ 无官方对手（MicroDuck 是 25cm，ODM 无人商业化） |
| 供应链 | ❌ XL330 进口无国产平替（S288 力矩存疑/12.6V/协议不兼容 ✅） | ✅ 深圳飞特国产直采（Feetech STS3215） |
| 工厂协同 | 友A/B 帮不上核心（舵机是进口成品） | ✅ PCB 友A + 结构模具友B 直接可用 |
| 安全 | 737g 桌面，风险低 | 2.1kg 需设计缓解（软壳/限速/防倾倒），目标 8+ |

### 1.3 推导与结论

1. **成本墙**：小鸭 ¥5500+ 硬成本 vs C 端 ¥1999-2599 → 结构性亏损，卖一台亏一台。大鸭 ¥2500-3000（原型）可盈利（量产再降）→ **大鸭**
2. **供应链墙**：XL330 = 进口 + 贵 + 无平替（原 BP 唯一物理硬约束）；STS3215 = 国产可直采，**「舵机依赖进口」的物理硬约束在开源双足层级被证伪** → **大鸭**
3. **差异化**：小鸭克隆 = 撞 $399 官方 + fanhao375 复刻党（★382，规模化成本更低）；大鸭 = MicroDuck 生态的「尺寸升级互补品」→ **大鸭**
4. **工程周期**：闭源逆向 6-12 月 vs 开源套件几周-2 月。Q4 窗口只允许大鸭 → **大鸭**
5. **同源性**：ODM 与 MicroDuck 是**同一位工程师**（Antoine Pirrone，Pollen R&D）的作品 ✅——大鸭 = 站在同源开源上做「更大版本」，训练方法论/sim2real 路径一脉相承，不是异类
6. **软件迁移成本可控**：orchestrator 行为层（7 原子/4 组合）硬件无关可迁移；行走策略 ODM 现成；踢球等技能重训走 ODM Playground（microduck-rl-fork 训练方法论/工具链全保留）

**结论：大鸭（ODM 42cm 路线）。六条公理全指向大鸭，小鸭仅「官方策略直接复用」一条胜（且被行为层可迁移削弱）。认的代价：25cm 官方策略不能直接用，部分技能需在 ODM 上重训（有现成路径）。**

### 1.4 决策后动作（v3.0 已执行/待执行）

1. ✅ 本 BP v3.0：产品规格改 42cm / 成本 ¥2500-3000 / 毛利场景重算 / 对比表 MicroDuck 行改「互补非竞争」
2. ✅ 共创会备料升级：ODM BOM/CAD/STL 底稿 + 同济子豪兄知识库（BOM 表/套件渠道）+ 问友B「ODM 结构件注塑模具报价」
3. ✅ 技术栈研究加入 fanhao375 仓 + ODM Playground
4. ⏳ M1 极客预售验证「42cm 大鸭」需求（N=200 gate）

### 6.2 新增（ODM 大鸭路线特有）

**① ODM 开源授权与品牌合规（中概率/中影响）**
- 事实：ODM 软件/硬件资产 Apache-2.0，商用合法 ✅；但「Open Duck Mini」名称/标识是原项目品牌，**不可直接用作 DuckMate 品牌**；Apache-2.0 保留版权声明义务
- 对策：整机以自有品牌（DuckMate）上市，开源组件按许可证保留署名与再分发声明（法务核对，Sky 合规背景兜底）；对外叙事「基于 Open Duck Mini 开源架构」而非冒充官方；差异化靠自研层（IP 外观/中文内容/主板/渠道），与开源本体边界清晰
- 反方预答：「官方以后收紧授权怎么办？」→ Apache-2.0 是不可撤销的永久授权（已发布代码），最坏情形 = 官方后续版本闭源，我们 fork 冻结版本即可，无断供风险 ✅

**② 2.1kg 儿童安全（中概率/高影响）**
- 事实：42cm/2107g 地面机器人，对 8-14 岁儿童存在倾倒/砸伤/夹手风险（MicroDuck 737g 无此问题——这是大鸭路线的真实代价，决策时已认）
- 对策（产品设计要求，非路线否决项）：①软壳包覆（IP 外观件同时是缓冲层）②限速模式（儿童模式最高步速下调，⚠️ 具体限速值量产前做跌落/冲击测试定标）③防倾倒检测（IMU 已有 → 软件层倾倒预判 + 主动坐倒）④目标用户 8+ 监护人陪伴（包装/说明书/App 明示）⑤重心低置设计（电池舱下移）
- 验证：M2 原型 500h 耐久 + 跌落测试并入 gate；儿童安全合规（玩具 GB 6675 类目判断 ⚠️ 需共创后专业评估——若判定为玩具需 3C 认证，列入 M1 合规清单）

**③ 策略重训周期风险（中概率/高影响——大鸭最大技术不确定）**
- 事实：ODM 走路策略现成 ✅，但踢球等差异化技能需在 ODM Playground 重训；MicroDuck 系单技能训练 1-2h GPU 时间（4096 env）✅，但**工程周期**（参考动作设计 + 调参 + sim2real 迭代）不是 GPU 时间，是人力周数
- 对策：①V1 技能集刻意贴着 ODM 现成能力选（走/坐/站/恢复 = 零重训），自训技能只做 1-2 个拳头项（踢球）②训练轨 M1 gate = 跑通一个最小重训技能（§3.3 诚实标注）③microduck-rl-fork 方法论迁移（verify_kick_window 已实证）④备选：V1 缺的技能用行为编排层组合现成原子动作顶替（7 原子/4 组合可组合出新行为的演示效果，virt-duck-plan ✅）
- 反方预答：「内容金字塔 V1 要 3 游戏 3 课程点，策略不够怎么办？」→ V1 内容贴能力边界设计（3 游戏 = 指挥家/追球/情绪剧场，均可用走路 + 已有原子动作编排实现，非全要新 RL 策略）✅
