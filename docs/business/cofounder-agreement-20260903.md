## 一、我们为什么一起做

### 1.1 机会（一句话）
MicroDuck 证明了「$399 双足机器人」全球爆单，但中国无渠道、非教育定位、供应链在欧洲。我们三人恰好拥有把「已验证的开源机器人」以国产成本、AI 素养教育定位、IP 形态带给中国用户的全部能力。

### 1.2 为什么是我们三个（能力互补矩阵，v2.0 诚实版）

| 能力环节 | 谁有 | 谁缺 | 备注 |
|---|---|---|---|
| PCB/PCBA 量产 | ✅ 友A（代工厂实控人）| Sky、友B | ⚠️ 待确认：原理图**设计** or 仅代工 |
| 精密结构/模具/外观 | ✅ 友B（黄金首饰模具，微米级）| Sky、友A | ⚠️ 待确认：结构**设计** or 仅加工 |
| 产品/商业/渠道/合规/出海 | ✅ Sky（16 年支付电商）| 友A、友B | |
| AI 素养内容（内容方法论）| ✅ Sky（方法论已验证，12 课 4 轮审计）| 友A、友B | v2.2：内容金字塔四层，体系化待建 |
| 仿真/RL/上层应用技术验证 | ✅ Sky 侧工作区（已实测跑通）| 友A、友B | 稀缺的「开源栈驾驭」能力 |
| 嵌入式固件/App 工程化 | 🟡 三方均缺 | 全员 | 可补：开源 131 Rust + 招 1-2 名工程师 |
| 资金/融资 | ✅ Sky 主导 + 三人共担 | — | |

**核心判断**：消费机器人创业最大死因 = 硬件成本压不下 + 内容养不起。我们三个把「成本端」（两家工厂）和「内容端」（Sky 的 AI 素养内容判断力 + 品控方法论，非现成课程体系）同时握在手里——这个组合在早期创业里极其罕见。技术审计结论：能力约 60% + 缺口 40%（90% 可补），唯一物理硬约束是舵机（详见 §1.4）。

### 1.3 共同目标（12 个月，v2.2：极客优先）
M0 共创对齐 → M1 需求验证（**极客预售意向 + 家长访谈 + 机构试探 3 家**）→ M2 原型 10 台 → M3 预售 500 台（极客 + C 端）→ M4 交付（详见 BP §11）。

### 1.4 技术能力审计结论（v2.0 新增——共创前必读）

> 完整审计见同目录独立分析文档。核心三条：

1. **我们不是「已具备全部能力」，是「约 60% 核心能力（制造+商业+开源栈驾驭）+ 40% 缺口，90% 可补」**
2. **唯一物理硬约束 = 舵机**：友B 能做机械部分（齿轮/壳体），但电机/编码器需进口——共创首日必须拿到批量报价
3. **⚠️ 本场必问（决定融资故事）**：友A/友B 你们做的是「**设计**」还是「**代工/加工**」？
   - 代工 = 别人给图纸你生产；设计 = 你能画原理图/做结构设计
   - 如果只是代工，我们宣称的「供应链强项」实际是「制造执行」——护城河要降级评估，融资故事要改
   - 无论答案如何都不影响合作（开源图纸 + 外协可补设计），但**影响怎么讲故事、怎么分期权**

**技术补强计划**：前 6 个月招/外协 1-2 名工程师（嵌入式/Rust ×1 优先，全栈/RL ×1 次之），约 ¥150-230 万/年——这是正常创业补强节奏，不是短板遮羞。

## 二、合作模式设计（核心议题，建议优先讨论）

### 2.1 三种可选模式

| 模式 | 结构 | 优点 | 缺点 |
|---|---|---|---|
| **A. 纯订单价** | 友A/B 以供应商身份接单，Sky 公司持股 | 朋友工厂利润动机纯粹；Sky 决策快；不涉及股权稀释 | 朋友只赚加工费，分享不到品牌增值；长期激励弱 |
| **B. 纯股权** | 三人按贡献持股，成立新公司 | 利益绑定最深；一起扛品牌 | 股权分配难公平；工厂主业与新项目利益冲突时难处理；朋友要承担公司亏损风险 |
| **C. 订单价 + 期权池**（推荐）| 友A/B 按订单价供货 + 新公司预留 10-15% 期权池，按里程碑授予 | 前期现金交易风险隔离；中期用期权绑定品牌增值；两全 | 期权设计需专业意见；兑现条件要写清 |

### 2.2 推荐：模式 C（订单价 + 里程碑期权）

**理由**：
1. **风险隔离**：项目尚未验证（舵机成本/需求都是未知），此时让朋友放弃工厂主业利润来赌股权 = 不公平且难谈拢
2. **动机纯粹**：订单价让友A/B 的工厂利润与项目成功正相关，无「股东价 vs 市场价」扯皮
3. **未来可转**：M2 原型验证后，若项目成立，可按约定估值将部分期权转实股——给朋友「上车」通道

**期权池建议框架**（最终需律师审）：
- 总池：新公司 10-15%
- 友A：硬件达标授予（如原型通过 + 量产良率 ≥95%）
- 友B：结构达标授予（模具交期 + 单件成本达标）
- Sky：全职投入，创始股 + 期权池管理权
- **v2.0 建议：若 §1.4 必问答案是「仅代工/加工」，期权池侧重订单量里程碑而非设计贡献**（设计贡献的外协成本已在订单价体现）

### 2.3 需要三人现场拍板的四个问题
1. 模式 A/B/C 选哪个？（推荐 C）
2. 若 C：期权池比例、授予里程碑、行权价怎么定？
3. 项目公司股权：Sky 是否绝对控股（≥67% 决策权）？还是三人均分？（强烈建议 Sky 控股——决策效率，且 Sky 承担主要资金与全职投入）
4. 若走 B：朋友工厂产能冲突时（自家大单 vs 项目单）优先级怎么排？

## 四、资金安排

### 4.1 阶段资金（人民币万元，框架）

| 阶段 | 金额 | 来源 | 用途 |
|---|---|---|---|
| M0-M1 验证期 | ~10 | Sky 自筹（或三人均摊）| 报价单/访谈/差旅 |
| M2 原型期 | ~120 | 天使轮（若已融）或 Sky 垫付 | 打样/开模/物料 |
| M3-M4 量产期 | ~170 | 天使轮 + 预售回款 | 首批 500 台 |

### 4.2 朋友工厂结算原则（模式 C 下）
- 一律按**市场订单价**结算（不要求朋友让利——朋友的工厂利润就是项目成本的一部分，但朋友需给「最惠价格」：不低于其最大客户的价格）
- 付款账期：≤30 天（项目公司现金流压力由融资解决，不转嫁给朋友工厂）
- 模具投入：前期开模费可谈「模具费摊销」（量产达量后退还模具费，行业惯例），降低朋友资金占用

## 五、决策机制

| 事项 | 决策人 | 说明 |
|---|---|---|
| 战略/融资/定价/渠道 | Sky（需通报）| CEO 职权 |
| 硬件方案/供应商选择 | 友A + Sky | 成本与质量双签 |
| 结构方案/模具/外观 | 友B + Sky | 同上 |
| 大额支出（>¥10 万）| 三人一致 | 防单点 |
| 股权/期权变更 | 三人一致 | 重大事项 |

**原则**：专业的事听专业的（友A 的 PCB、友B 的结构、Sky 的商业），方向的事 Sky 拍板但充分通报。分歧升级路径：先一对一 → 三人会 → 外部顾问。

## 六、知识产权约定（建议）

1. 开源软件（Apache-2.0）：合法复用，但**自研层（主板设计/结构件/内容金字塔（人格包/游戏包/课程点）/品牌）归项目公司所有**
2. 友A 在本项目开发的主板设计：**知识产权归项目公司**（友A 工厂享优先生产权）
3. 友B 在本项目开发的结构/模具：**知识产权归项目公司**（友B 工厂享优先生产权）
4. 双方各自工厂的既有技术/工艺/客户：**不因本项目转移**
5. 保密：三人对项目商业信息互负保密义务
6. **v2.0 补充**：若设计环节外协（§1.4 答案是仅代工时），外协设计成果同样归项目公司，友A/B 工厂享优先生产权

> ⚠️ 知识产权归属是朋友合作最容易翻车的点，建议下周明确表态，正式文件由律师起草。

## 七、退出机制

| 情形 | 处理 |
|---|---|
| 项目失败清算 | 按出资比例分担；期权池失效；知识产权归项目公司处置 |
| 某方中途退出 | 已投入按约定结算；期权未授予部分自动失效；竞业限制（1 年内不从事同类项目）|
| 项目成功融资/并购 | 按股权/期权兑现；订单价模式的朋友无股权收益（仅加工利润）——这正是模式 C 期权池的意义 |
| 严重分歧不可调和 | 友好分拆：Sky 保留品牌/软件/渠道；工厂朋友保留各自产线，按市场价继续供件 |
