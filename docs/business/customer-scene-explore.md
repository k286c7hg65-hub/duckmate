## 一、第一性重问（保留，依然成立）

**谁最愿意为「会走路的 AI」付钱？**
1. 谁有「必须买」的理由？→ 机构（教具）、特教家庭（刚需）——但「有需求」≠「我们能做」
2. 谁的付费决策快？→ 极客（冲动）> 机构老板 > C 端家长
3. 谁能持续付费？→ 机构（新课）> C 端订阅
4. 三人组合（供应链+内容+ToB/ToC）最能服务谁？

**v1.0 的错误**：把「有需求」直接当「可进入」——跳过了渠道能力/资质/账期/品牌的现实约束。

## 三、收敛后的核心判断

**这不是「场景火箭」，是「一条主路径 + 一个试探」：**

```
主路径：L1 极客验证（0-6月）→ 验证产品+拿现金+攒口碑
        ↓ 口碑外溢
        L2 C 端家庭（6-18月）→ 品牌+订阅（Sky 课程内容先行）

试探：  教培机构 3 家试用（平行）→ 有效则作为 C 端放大器，无效即砍
```

**为什么极客是第一战场（唯一有现成证据的）**：
- MicroDuck 8/27 爆单的人群就是极客/开发者（官方博客 + HF 联创背书）
- 中国真空明确（官网 FAQ 无中国、税运 ¥3500+）
- 决策快、毛利高、售后负担低、品牌放大器（发烧友→KOL→大众）
- 我们的内容素材已就绪（工作区技术验证 + demo 视频）

**为什么 C 端是主战场但不是第一**：
- AI 素养教育定位成立（家长焦虑已转向 AI），但**中国家庭付费意愿未验证**——M1 必须测
- 需要教育内容体系（Sky 可迁移）+ 品牌信任，是长线投入
- C 端品牌从极客口碑长出来，比广告投放便宜

**教培机构为什么只是「试探」**：
- 「机构需要真 AI 教具」是我的推断（双减后活下来的机构有转型动力）——**没有一手证据**
- 试点 3 家免费试用 30 天看续费 = 30 天内可验证，验证不过就砍，不恋战
- 机构真正的价值 = B2B2C：机构买了 → 家长看到 → C 端转化

## 五、反方自检（v2.0 承重柱）

**反方一：「砍掉学校/特教，市场故事变小了，投资人怎么讲？」**
- 回应：v1.0 用学校/特教凑 TAM 是**假大**——不可进入的市场在财务模型里是噪音。真实的投资故事 = 「极客验证 → C 端品牌」的清晰路径 + 诚实披露「B 端我们暂时不做，因为碰不了」。投资人更信「知道自己吃哪碗饭」的团队，不信「全都要」的 PPT。
- 残留：TAM 数字会缩水（见 BP v2.1 修正），接受——真实比好看重要。

**反方二：「极客市场小（几千台天花板），撑不起创业。」**
- 回应：极客是**冷启动不是终点**（MicroDuck 自己也从创客走向大众）。极客阶段的目标不是市场规模，是验证（产品真能用）+ 现金流（不烧钱等融资）+ 口碑（C 端信任的种子）。C 端才是规模市场。
- 残留：若极客预售 N<100，说明产品力不行，C 端更没戏——这个 gate 是好事。

**反方三：「教培机构试点是不是还在 YY？」**
- 回应：区别在于——学校/特教是**结构性不可进入**（资质/渠道/准入），机构是**可验证假设**（3 家免费试用 30 天，看续费）。可验证 ≠ YY；YY 是不可验证还写进 BP。机构这条线**不进 BP 正文**，只作为 M1 的试探动作之一。
